# AICE Video Studio — downloads

An offline desktop video editor for Windows 10 and 11, by [AICE Services](https://aiceservices.com).

**Website:** https://tulaibhasan.github.io/aice-video-studio-releases/

## Install

1. Open the [latest release](https://github.com/tulaibhasan/aice-video-studio-releases/releases/latest) and download `AICE-Video-Studio-v…-setup.exe`.
2. Open it. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.
3. That's it. When a new version comes out, the app shows **Update now** and installs it for you.

Each release also has a portable `.zip` (no installer) and a `.sha256` checksum for the installer.

This repository holds only the downloads and the website. ffmpeg (GPL v3, from
[BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds)) is bundled; its licence and source
links are in the app's `ffmpeg` folder.
